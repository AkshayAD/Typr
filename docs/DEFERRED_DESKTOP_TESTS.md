## Resume checklist

Use an isolated synthetic profile and disposable text fields, preserving personal settings/history/clipboard. Start with the smallest checks; stop if audio/input behaves unexpectedly.

1. **Microphone lifecycle.** Observe Windows' microphone indicator through launch, Prepare speech, idle, shortcut start, release/finish, Esc, capture error, unload and exit. Launch/preparation/idle must stay off; finish may retain the documented 300 ms ending tail. No late open after a short press, release, Esc or bar drag during cold preparation. Confirm actual first/end words, not only indicator state.
2. **Real shortcuts.** Physical Ctrl+Alt in both modifier orders, left/right keys, Shift for Raw, Space hands-free, toggle start/finish, repeat paste and conflicts. Disable keyboard shortcuts and verify they are released. Only explicit recording shortcuts start by default. Enable bar/button recording deliberately, then test hold/click/finish/cancel and disable it again.
3. **External paste.** Disposable native editor and browser text area: multiline English, Roman Hindi, numbers and bullets; then focus changes, cancelled finalization, password/read-only/elevated fields, busy clipboard, rich formats and a newer user copy. Verify one correct insertion, preserved clipboard and Copy recovery. Never use active messages/private documents.
4. **Transparent movable bar.** Light/dark/system/high contrast; 20/78/100% opacity; all three sizes and hover delays; drag from each icon, hold control and background. Release at arbitrary positions on all four work-area edges, including their midpoints: top/bottom must be horizontal (96 by 16 DIPs at default size), left/right vertical (16 by 96), with 2x inward hover growth and an 18 DIP inset. No action fires after a drag. Hover controls stay reachable and anchored; right-click choices match settings. Test live text on/off, hide/show, bottom-center reset and restart persistence.
5. **Monitors and accessibility.** 100/125/150% DPI and mixed DPI; negative monitor positions, disconnected monitor, taskbar/work-area changes and edge clamping. Verify caption/menu popups on every edge, including placement when the work-area and popup coordinates use different DPI scales. Check text/icon contrast, keyboard focus and screen-reader labels. Test physical dragging across displays.
6. **Calls, videos and games.** With a built-in/USB Typr input, verify another call retains its own mute/input state and videos/games retain playback. Then deliberately select a Bluetooth headset microphone and observe the documented Windows Classic profile change and recovery. Typr must not change Windows defaults, volume/mute or output capture. Recheck unavailable/unplugged input failure and deliberate picker refresh.
7. **Provider connection and quality.** User completes each official CLI's sign-in in the prepared app flow. Test expired/limited connections, priority/fallback rules, live catalog/efforts and the same consented English/Roman-Hindi correction corpus. Verify no added preamble/postscript, meanings/names/digits/lists/corrections, exact selected model, cancellation and raw/local recovery. Initial Luna comparison predates final private-profile isolation; final authenticated inference needs this check.
8. **History and audio.** Explicitly opt in within the test profile. Replay synthetic audio; preview/discard/apply re-polish and Small re-transcription; restore text/provider/model/effort; test missing audio/models and restart. Large v3 is optional and has not been downloaded/benchmarked.
9. **Efficient recognition.** The baseline plus one small candidate synthetic comparison is complete: the candidate used fewer resources but misheard the opening, so it did not replace the default. Follow the natural-voice corpus procedure in [model research](ENGLISH_MODEL_RESEARCH.md#bounded-benchmark-for-the-next-user-approved-idle-window) before selecting another engine. No bulk model downloads or gaming-time inference.
10. **Resource modes.** Observe Automatic following a recognized Windows Game Mode event and the manual Gaming/Everyday overrides. Idle gaming must unload speech, hide the bar, stop target polling and release shortcuts without modifying saved preferences. Test a current dictation finishing and cancelling, pending native initialization, cold preparation, downloads/reprocessing/comparisons, mode flips and shutdown. Exiting gaming may prepare a previously prepared model but must keep input off. Check unrecognized/windowed games with manual Gaming. Actual game frame-time, thermal/battery impact and OS callback transitions remain unmeasured; GPU evidence comes from synthetic replay and native integration checks, without an active game or call.
